- **路由判据**：改的输入被谁消费 → 是否重建候选；
- **终态**：一条管道，PlanningRequest 变成 DSL 编译产物；旧正则迁移为规则层（不重写）。

## 2. 关键设计结论（供评测模块参考）

- **确定性分层**：LLM 只翻译不判断；校验器确定性；编译产物进指纹/证据链。
  "可复现"承诺从"NL→模型"降级为"DSL→模型"。
- **三层解析**：规则（正则直出）→ 非修改门控 → 旧规划语言桥接 → 意图门控 → 向量检索(few-shot) → LLM。
  顺序不是反的；向量层做"模板检索"而非"意图分类"（开集结构化生成）。
- **路由**：`registry/parameters.py::consumption_point()`；
  海况在生成层，风速/电价在选择层（时序数据不是铁板一块）。
- **生成层参数化**：候选开工粒度、跨天暂停、夜间转移、海况阈值（改参数即重算候选）。

## 4. 测试与评测体系（现状）

### 跑法

```powershell
cd backend
py -m pytest -q                              # 快测 253（默认排除 slow）
py -m pytest tests/dsl/ -m slow -q           # 慢测 22（真求解，约 20 分钟）

py -m eval_cases.run_dsl_question_bank --solve 5  # 抽样求解验证
py -m eval_cases.run_dsl_golden                   # DSL golden
py -m app.evals.run_eval backend/eval_cases/compile_cases.jsonl   # 旧发布闸门
```

## 6. 已知边界

- 风险概率/天气条件约束/备件预留构件、允许跨海事窗口维修：按业务决定不做；
- max/derived 具名量经 metrics 已支持（总经济成本/现金支出/最后完工时间）；
- co_occur 仅 same_day/diff_day；linear 不允许混合时间量与成本量；
- LLM 个别模糊话术运行间差异（已用验收模式显式记录）；
- 完整 25 任务模型短时限不可证明（生产默认 300s）。
