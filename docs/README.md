## 设计稿与过程材料

- `superpowers/specs/` —— 每份是某个能力开做之前的设计稿（会话记忆、工具架构、注册驱动意图……）
- `superpowers/plans/` —— 对应的施工计划，末尾常附"计划与实现的偏差"
- `conversation-exports/` —— 早期与 AI 的设计对话原始记录（未整理，保留原貌）
- `prototype/` —— 最早的单文件 HTML 原型，双击即看，不需要后端
- `sample-run/` —— 一次真实求解的产物切片，配合 [一次求解留下了什么](一次求解留下了什么.md) 读

> 这些过程材料故意保留：设计和实现之间的偏差都在这里，删掉就只剩结论了。
