# 引擎切换：规则优先 vs LLM 优先（2026-11-01）

> 用户目标：前端一个按钮选引擎（规则优先 / LLM 优先），**默认 LLM 优先**，启动即默认。
> 已拍板：**只切理解层**（谁把句子解析成 DSL）+ **进程内 import**。

## 关键事实（摸清后确认）

- llm-first 实际 route 词表：`("dsl", "not_change", "reject", "clarify")`（`contract.py:17`）。
- backend `llm_parser` route 词表：`dsl / batch / data_patch / not_change / reject / clarify`。
- 两者在 `dsl / not_change / reject / clarify` 上重叠，**映射干净**。
- `pipeline.understand(utterance, ctx=...)` → `Outcome(route, dsl, ...)`，纯函数、可进程内调（`pipeline.py:286`）。
- 两个引擎的 DSL 产物同形，下游 dsl_core 编译/求解可直接复用。

## 缝（dispatch 点）

backend 的 `_try_dsl_parse`（`agent_runtime.py`）现在固定走 `llm_parser.parse()`。改成：

```
if engine == "llm":
    outcome = llmfirst.pipeline.understand(content, ctx=...)
    → 映射成 (route, dsl)
else:
    result = llm_parser.parse(content)
```

route 映射：`llm` 的 `dsl` → 走求解链；`reject`/`clarify` → 同现有；`not_change` → 落回 conversation_agent。

## 执行步骤

1. **命名空间 llm-first** ✅——`llm-first/src/` 扁平模块包进 `llmfirst/`，paths.py 挂载收进 `llmfirst/__init__.py`；修 4 处路径深度。llm-first 测试 169 过。
2. **backend 加引擎 dispatch** ✅——`_try_dsl_parse` 读 `self._tls.engine`（线程本地，随请求设置），`llm` 走 `_llm_first_parse`（`pipeline.understand` → `ParseResult`），`rule` 走原 `llm_parser.parse`。未配置 key 时 `_llm_first_parse` 返回 None 回退规则路径。
3. **flag** ✅——API `AgentMessageRequest.engine: Literal["llm","rule"]`，`submit/stream_message` 透传；**默认 LLM 落在前端**（切换控件默认 llm 并显式发送），API 默认 `rule` 保持旧行为、测试不破。
4. **前端按钮** ✅——`agent-topbar` 加「LLM 优先 / 规则优先」分段切换，store 持 `engine` 状态（默认 `llm`），随每条消息发送。
5. **LLM 配置统一** ✅——`llmfirst.client.api_key()` 加 `MINIMAX_API_KEY` 回退；backend 进程内 import 时用同一把 DeepSeek key。
6. **回归** ✅——backend 373 过、frontend 58 过、llm-first 169 过；LLM 引擎功能实测 `route=dsl` 出参数。

## 结果（已落地）

- 前端「一修」顶栏出现「LLM 优先 / 规则优先」切换，默认 LLM；点击即时切换，下一条消息即用所选引擎。
- 后端按请求 `engine` 字段分派理解层；llm 引擎不可用（无 key / 包缺失）时优雅回退规则路径。
- 两个理解层产出同一 DSL 形状，下游 dsl_core 编译/求解/版本链路不变。

## 遗留/风险

- llm-first 的 `session.Context`（今天日期 + 参数现值）与 backend 的 `WorkingMemory` 不是一套，映射要小心。
- `not_change`（llm）对应 backend 的哪些下游还没定死，先落回 conversation_agent。
- rulebench 的规则侧 import 仍在 llm-first 内，本次不碰。
