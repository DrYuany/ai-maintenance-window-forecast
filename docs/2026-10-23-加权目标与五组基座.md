# 加权目标与五组测试基座

日期：2026-10-23。技能目标模板版本升至2.0。

四种标准策略现在各支持“分层”和“加权”两种模式。分层仍为默认，按已注册的目标顺序严格求解；加权模式对每个指标按其线性表达式在已声明变量边界内的有限上下界做区间归一化，再构造一个最小化加权总目标。最大化指标先转成损失方向。默认权重和策略含义保存在技能 `references/四种目标模板.json`，用户可以为所选策略显式提供完整的指标权重覆盖。

加权模式不能代替服务硬约束。安全、海事窗口、库存、批准承诺、正式期限、共同必修任务和最低完成数仍是原模型约束。加权目标表达允许目标间折中，所以“高风险优先”加权模式下，严重度数量不构成绝对优先保证；若业务要求必须完成，应设置必修或截止约束。

测试基座配置在 `data/场景评测/五组基座配置.json`，生成器为技能 `scripts/generate_base_scenarios.py`。五组分别是标准基准、偏高风速、偏低风速、高电价波动和较差海况。每组导出海事窗口、每日海况、小时电价/风速/曲线出力，以及包含原始参数的场景快照。窗口长度保持5—10天、间隔至少3天，所有窗口均明确标为合成假设而非实际批准。五组是打包变化的综合情景，有些情景同时改变窗口日期和天气或价格；直接比较不能将结果差异归因于某个单一因素。要估计单一因素影响，需固定其他输入，只复制并覆盖该因素。

10MW基准曲线设切入4.0m/s、额定11.4m/s、切出25.0m/s，额定以下暂用三次方归一化简化公式。配置同时含8个部件按高/中/低等级的剩余出力比例。该表明确属于初版模拟假设，需要用SCADA、厂家限值或现场运行记录校准。故障等待期间按剩余出力比例计算机会损失；维修期间整机停机。第一阶段不另叠加每日潜在风险金额，以免重复计入未校准的损失。

本次项目测试共38项通过。基座测试检查5组各3个窗口、35行日海况、840行小时数据和快照；目标模板测试检查四种策略的加权默认值、合并目标、标准化范围、非法权重拒绝及共同服务约束。五组基座尚未接入项目六任务成本算例编译器；降额参数已写入配置和 skill 规则，但这不等于当前全场排程已按这些数据重新求解。独立前向测试发现并促使修正文档示例的完整权重映射要求，并明确含严重度偏好的组合应使用包含该指标的注册模板。
