# 稳定性：同一句话跑多遍

> 由 `python scripts/bench_stability.py -n 5 --save` 生成

每条跑 **5** 遍。三条结论：

1. **最终动作会抖**：0/10 条在不同轮次给出过不同 route（无）。
2. **退回重试确实在干活**：1/10 条触发过至少一次重试（相对时间）。
3. **重试之后仍判死的**：0/10 条（无）。

规则侧那一列在每一轮里都一样——拿它当基线，抖动的只能是模型侧。
