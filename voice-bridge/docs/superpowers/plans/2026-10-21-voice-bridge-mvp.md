# 随声译 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver an Android-first Chinese monologue translator with configurable pause detection, context-aware English translation, adjustable speech playback, voice selection/cloning authorization, per-conversation usage limits, and shared PWA/APK client.

**Architecture:** Build a standalone React + TypeScript + Vite client in `voice-bridge/web`, a FastAPI service in `voice-bridge/server`, and a Capacitor Android wrapper in `voice-bridge/android`. The client stores transcripts and bounded conversation context in IndexedDB; the server owns credentials, device-bound conversation IDs, quota reservations/accounting in SQLite, and adapters for Volcengine speech services and Alibaba Qwen Flash.

**Tech Stack:** React, TypeScript, Vite, IndexedDB, MediaRecorder/Web Audio API, Capacitor, Python 3.10+, FastAPI, SQLite, httpx, FFmpeg/ffprobe, Volcengine ASR/TTS/voice cloning, Alibaba Model Studio `qwen-flash`.

---

## Scope and key decisions

- Product requirements are defined in `docs/superpowers/specs/2026-10-21-voice-bridge-design.md`.
- Implement the MVP with the Qwen Flash cloud API. Keep LLM integration behind a backend adapter; a self-hosted OpenAI-compatible endpoint is a future configuration option and is outside MVP acceptance.
- PWA and Capacitor APK share the same frontend and backend API.
- Do not persist audio or full conversation history on the server. Store transcript, translation, summary, and preferences in local IndexedDB.
- Use server-issued device-bound conversation IDs, 10 active conversations, per-conversation 24 hour / 1.5M-token limits, and retained device-wide 240 hour / 15M-token limits.
- Quota reservations and settlement must be transactional. Unknown usage after a dispatched LLM call remains reserved and is reconciled or settled at the conservative reservation ceiling.
- A deleted conversation is permanently tombstoned; its remaining quota is forfeited and its ID cannot be restored.
- Do not implement visual polish or public deployment in this phase.
- Per developer instruction, do not add or run automated tests unless the user asks. Use build/startup checks only when needed to confirm runnable artifacts.

## File map

### Web client (`web/`)

- `web/package.json`, `web/vite.config.ts`, `web/tsconfig.json`, `web/index.html`: frontend toolchain and PWA entry.
- `web/src/main.tsx`, `web/src/App.tsx`: React bootstrap and top-level application state/navigation.
- `web/src/api/client.ts`, `web/src/api/types.ts`: typed API client and wire contracts.
- `web/src/audio/recorder.ts`, `web/src/audio/silence-detector.ts`, `web/src/audio/player.ts`: recording lifecycle, client-side VAD countdown, and adjustable playback.
- `web/src/storage/db.ts`, `web/src/storage/conversations.ts`, `web/src/storage/settings.ts`: IndexedDB persistence for conversations, bounded context, and device preferences.
- `web/src/features/session/`, `web/src/features/conversations/`, `web/src/features/recording/`, `web/src/features/results/`, `web/src/features/voices/`: user flows and minimal functional screens.
- `web/src/styles.css`, `web/public/manifest.webmanifest`, `web/public/icons/`: basic responsive styling and PWA install assets.
- `web/capacitor.config.ts`, `web/android/` (generated by Capacitor): native wrapper configuration and Android app.

### Backend (`server/`)

- `server/pyproject.toml`, `server/README.md`, `server/.env.example`: dependencies, run/configuration instructions, and credential template.
- `server/app/main.py`, `server/app/config.py`, `server/app/security.py`: FastAPI entry, settings, signed session/device cookies and CORS.
- `server/app/db.py`, `server/app/models.py`, `server/app/quota.py`: SQLite schema, conversation ownership, tombstones, transactional reservations and usage settlement.
- `server/app/routes/session.py`, `server/app/routes/conversations.py`, `server/app/routes/translations.py`, `server/app/routes/voices.py`: HTTP endpoints.
- `server/app/services/pipeline.py`, `server/app/services/audio_validation.py`: ASR → translation → TTS orchestration and uploaded audio validation.
- `server/app/providers/llm.py`, `server/app/providers/qwen.py`, `server/app/providers/volcengine_asr.py`, `server/app/providers/volcengine_tts.py`, `server/app/providers/volcengine_clone.py`: provider interfaces and cloud adapters.
- `server/app/services/audio_cache.py`, `server/app/services/asr_audio_store.py`: bounded TTS cache with ownership-aware retrieval and single-use, short-lived in-memory audio URLs for Volcengine ASR.

### Root docs and Android packaging

- `README.md`: product quick start, cloud configuration, local run, HTTPS sharing, Android build, consent/privacy and cost notes.
- `android/` under the web package: Capacitor-generated native project; debug APK is built only if Android SDK/JDK are available.

## Completion criteria

- The app runs locally with a usable mobile flow and requires no cloud secret in frontend code.
- Configured provider credentials enable the full record → ASR → context-aware translation → TTS → playback path.
- Device-bound conversations and both quota layers are enforced transactionally, including failures after provider dispatch.
- Conversation data persists locally; recording and generated audio are not persistently stored by the backend.
- Silence threshold, speech speed, preset voice selection, and voice-clone consent controls work in the client.
- PWA installation metadata and Capacitor Android project are present; APK build status is documented.
- No visual redesign or public deployment is included.
