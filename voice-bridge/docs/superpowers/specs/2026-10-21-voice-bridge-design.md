# 随声译（工作名）产品设计规格

**日期：** 2026-10-21  
**状态：** 已补齐上下文对话、安全配额及模型部署选项，待用户确认  
**目标：** 为 Android 用户提供一款可分享的语音口述翻译工具：录完一段中文后得到英文文本和英文语音，并能控制停顿结束判定、播报速度和音色。

## 1. 产品目标与首发范围

用户会长时间、大段地自言自语，希望把口述内容转成英文并听到英文播报。首版是功能验证原型，面向用户本人和受邀朋友，优先在 Android Chrome 使用，同时提供可安装的 Android APK。网页和 APK 共用一套 React 前端。

首版包含：

1. 中文录音，支持手动结束及可调的静音结束判定。
2. 录音完成后依次执行中文语音识别、使用大语言模型结合对话上下文翻译成英文、英文语音合成。
3. 展示识别原文和英文译文，并支持播放/暂停与语速调整。
4. 选择几种英文预置音色并试听。
5. 上传或录制声音样本创建个人音色；克隆第三方声音前须确认已获得声音本人授权。
6. 可创建、切换和删除对话；最多保留 10 个对话窗口，每个窗口独立保留文字上下文和用量。
7. 页面以功能优先，只实现对话列表、录音、结果、声音设置必要状态，不在本阶段做视觉精修。

首版不包含：实时边说边翻译、自动回答口述内容（模型只翻译，不接话）、多人账户、跨设备历史同步、后台录音、商店上架、公开商业化和复杂品牌视觉系统。

## 2. 用户流程与交互

### 2.1 口述翻译

1. 用户进入录音页并授予麦克风权限。
2. 点击开始，录制整段中文；页面显示录音状态和经过时间。
3. 用户可在录音过程中手动结束。若检测到静音持续达到设置阈值，显示“检测到停顿”提示和 3 秒倒计时；用户可点“继续说”取消自动结束。倒计时结束后进入确认页，显示录音时长并让用户选择“开始识别并翻译”或“继续录音”。只有点击确认后录音才会上传。
4. 默认静音阈值为 3 秒，允许 1–10 秒、每次 1 秒调整。阈值和语速保存在本机设置中。
5. 用户确认后显示处理状态。后端按“识别 → 带上下文的 LLM 翻译 → 合成”顺序执行，并返回任务 ID、识别原文、英文译文和短期音频地址。
6. 结果页提供原文、译文、播放/暂停、重播和当前语速控制。音频以 MP3 从独立播放接口分块传输，服务端只在内存中暂存，10 分钟后自动释放。用户可返回录音页重新开始。
7. 每条完成的原文/译文加入当前对话，存到本设备的 IndexedDB；用户可新建对话、切换对话、改名和删除。每个对话可见录音时长与 token 用量进度。

静音判定在客户端通过麦克风音频能量完成。它不会在说话时把音频逐段发送到服务端；录音结束且用户在确认页点击“开始识别并翻译”后，才上传录音处理。单段口述上限为 10 分钟或 25 MiB，以先达到者为准；接近上限时显示提示。

### 2.2 音色设置

- 首版列出少量经过账号授权的英语预置音色，显示名称、性别/音色描述和试听操作。
- 自定义音色流程支持录制 10–30 秒或选择音频文件（供应商单文件上限 10 MiB），展示上传限制和用途说明；需要的编码格式按服务支持列表校验。
- 上传他人声音时，必须勾选明确声明：已取得声音本人对采集、上传、克隆及使用范围的授权。该确认与音色记录一起保存。
- 克隆音色管理页提供“从本应用移除”操作。该操作立即从应用可选音色和本地音色记录中移除 ID；若供应商账号有对应删除入口，由账号持有人同时在火山引擎控制台删除供应商音色。首版不宣称本应用删除按钮能够删除供应商侧音色。
- 音色克隆完成后显示服务端返回的音色状态；只有成功且当前账号已获该音色合成权限时才能选用。
- 录音原件只在请求处理期间保留在内存中，不写入应用文件、数据库或浏览器缓存。云服务可能按其产品规则保存音色/训练数据，界面须在提交前说明并提供服务方隐私与协议链接。

### 2.3 语速

- 提供易理解的倍速控制，初始值 1.0×。
- 当前结果的播放采用 Android Chrome/WebView 支持的音频播放速率控制；浏览器支持时设置 `preservesPitch` 保持音高，不支持时允许音高随速率变化。后续合成请求也应可将语速映射至云服务的合成参数。
- 设置值写入本机存储，重开页面后保留。

### 2.4 对话与上下文

- 每台设备最多有 10 个活跃对话窗口。对话 ID 由服务端创建并绑定签名设备身份，客户端不能任意生成 ID。删除对话会删除本机历史并将服务端 ID 永久标记为已删除；ID 不可恢复或继续用于翻译，删除时明确告知用户该操作不可撤销。删除释放活跃名额，但不清除该对话已消耗的额度，也不退回剩余额度。
- 所有对话共享设备累计上限：已提交音频 240 小时、LLM token 15,000,000；即使删除对话也保留设备级累计用量。单对话仍受 24 小时和 1,500,000 token 限制，避免通过轮换对话重置额度。
- 原文、译文和上下文摘要保存在本设备 IndexedDB，不上传或同步完整历史。录音文件不保存。
- 滚动摘要使用 JSON 字段 `topic`、`entities_and_glossary`、`translation_preferences`、`unresolved_references`，上限 1,000 tokens。客户端校验结构和长度；模型摘要超限或无效时最多重试压缩一次，仍失败则沿用旧摘要、保留本轮译文并提示上下文未更新。最近 6 轮总计最多 8,000 tokens，超出时优先移除最旧轮次；完整旧历史仍可在本机查看。
- 模型只执行翻译，不回答、不建议、不续写用户的想法。新一轮翻译可参考当前对话中的术语、指代、语气和话题来保持前后一致。
- 每个对话累计录音时间最多 24 小时，累计 LLM 输入与输出 token 用量最多 1,500,000 tokens；两项任一达到上限即停止该对话后续云端处理，保留已有文字历史，并提示用户删除旧对话或另开新对话（若未达到 10 个上限）。录音时长只统计已提交处理的音频时长。
- 界面显示两类额度的当前用量、剩余额度和达到上限的提示。服务端根据 LLM 响应中的实际 usage 记 token；语音服务费用不计入该 token 额度。
- 阿里云百炼 `qwen-flash` 定价官方页面于 2026-10-21 查询，适用的 ≤128K 输入档列出输入/输出单价 ¥0.15/¥1.5 每百万 tokens。按全部 token 都按输出价计算，1,500,000 tokens 理论上限约 ¥2.25/对话，10 个对话约 ¥22.50；仅为 LLM 费用估算，不含 ASR、TTS、克隆音色和网络/存储费用。实际输入 token 占比会使估算低于该上限；价格、区域和模型供应情况可能变化，不构成价格保证。

## 3. 技术方案

### 3.1 客户端

- React + TypeScript + Vite，作为独立的 `voice-bridge/` 项目，不改动现有风电窗口预测项目。
- PWA 支持 Android Chrome 通过 HTTPS 访问、添加到主屏幕和分享链接。
- Capacitor 将同一套前端封装为 Android APK；使用系统麦克风权限并通过 WebView 的 MediaRecorder/Web Audio API 录音与检测静音。
- 客户端不直接持有云服务密钥。录音数据只存在页面内存；对话原文、译文、滚动摘要和偏好保存在当前设备 IndexedDB/localStorage，不做云端历史和跨设备同步。

### 3.2 服务端

- Python 3.10+、FastAPI，作为语音服务适配层。
- 服务端环境变量保存火山引擎 API Key、各资源 ID、共享访问口令、允许的 Web Origin 及公网 HTTPS `PUBLIC_BASE_URL`（供 ASR 服务获取短期签名的内存音频 URL）。
- 项目所有者在后端环境变量配置共享访问口令，并通过私下渠道发给受邀朋友。受邀用户打开网页或 APK 后先输入口令；服务端校验后签发短期 HttpOnly、SameSite 会话 cookie。口令绝不内嵌在 PWA 或 APK 资源中。
- 登录后另签发稳定的 HttpOnly `voice_device` cookie（签名设备 ID，有效期 365 天）用于隔离配额账本；访问会话 cookie 有效期 12 小时。提供“退出”操作只清除访问会话，保留设备 ID；客户端收到 401 时回到口令输入页。
- 对外接口建议：
  - `GET /api/health`：检查服务和必要配置状态，不返回密钥。
  - `POST /api/session`：使用共享访问口令换取短期 HttpOnly 会话 cookie。
  - `POST /api/conversations`：由服务端生成并注册绑定设备的对话 ID；达到 10 个活跃对话时拒绝创建。
  - `DELETE /api/conversations/{id}`：删除本地历史后将服务端对话永久标记为已删除，ID 不可恢复或复用；保留设备累计用量，剩余额度作废。
  - `POST /api/translations`：接收录音、语速、音色 ID、服务端签发的对话 ID、滚动摘要和最近 6 轮；依次调用 ASR、LLM 翻译和 TTS；使用服务端请求 ID/幂等键记录阶段状态；响应 JSON 含任务 ID、识别原文、英文译文、新摘要、实际 token usage 和 MP3 播放地址。
  - `GET /api/asr-audio/{token}`：仅允许带 5 分钟过期签名 token 的火山引擎 ASR 服务获取对应内存录音；ASR 必须在过期前下载。该端点不要求用户会话 cookie，但 token 必须不可猜测且限次访问。ASR 完成或超时后立即释放录音；服务端重启会清空内存并使链接失效，调用方返回可重试错误。
  - `GET /api/translations/{id}`：返回该请求当前阶段（处理中、成功、失败、用量待对账）及已结算/暂留额度；用于客户端在网络断开或上游超时后恢复状态。
  - `GET /api/translations/{id}/audio`：验证有效访问会话及任务所属 `voice_device` 与当前设备一致后，才允许从内存短期缓存分块播放 MP3；任务完成 10 分钟后过期。生成音频限制 15 MiB，超限返回可读错误并保留译文。
  - `GET /api/conversations/{id}/usage`：查询该对话和设备累计剩余的录音时长及 token 额度。服务端以 SQLite `BEGIN IMMEDIATE` 事务原子预留请求的音频时长及保守 token 上限（估算输入 tokens + 配置的最大输出 tokens）；无法预留则不调用云服务。ASR 调用前失败则释放音频预留；ASR 已派发后，音频时长按已提交处理计入。LLM 调用前失败则释放 token 预留；LLM 已派发后，无论后续 TTS 是否成功，只要收到 usage 就按实际 tokens 结算。如果超时/断连导致已派发请求的 usage 未知，先保留 token 预留并标为 `usage_unknown`，客户端通过请求状态接口轮询；服务端尝试供应商请求 ID 对账。对账成功按实际值结算；供应商不支持查询或在配置的对账截止时间（默认 10 分钟）仍未知时按预留上限结算并将请求标为失败，之后客户端才允许重试。请求阶段、幂等键和结算状态写入 SQLite；并发请求经事务串行校验，不能共同超额；完整文字历史仍只存客户端。
  - `GET /api/voices`：返回服务端配置的预置音色和当前音色列表。
  - `POST /api/voices/clone`：接收样音及授权声明，调用声音复刻服务并返回音色 ID/状态。
- 服务端限制请求体大小、音频时长和可接受格式；先执行容器/时长探测并强制校验 10 分钟上限，无法探测的格式拒绝处理。客户端同时做时长提示。为会话和克隆接口加基础速率限制。错误响应要区分麦克风录音、配置缺失、上游超时、配额/权限不足和上游服务错误，不泄露凭证。
- 原始录音 Blob 在页面内存保留到处理成功、用户丢弃或页面关闭；上游处理失败时提供“重试处理”和“丢弃录音”操作，重试前不要求重新录音。失败重试会创建新的服务请求/预留；已派发至 ASR/LLM 的上次请求按上述规则记账，可能重复产生上游费用。服务端处理和临时音频缓存均只留在内存，重启即清空。
- 共享访问口令只用于内部和朋友演示，不代表多租户隔离。任何获得口令的使用者可消耗同一云账号额度；部署说明必须提示只向信任的人分享并在云控制台设置预算/告警。
- 共享口令登录后另发 365 天签名 `voice_device` cookie；清浏览器数据、重装 APK 或丢失该 cookie 会创建新的设备额度身份，因为无账号体系，此为按安装实例的演示级限制，不是强反滥用机制。所有对话 ID 均由服务端签发并做设备归属校验。

### 3.3 云端处理

- 火山引擎豆包语音录音识别、TTS/声音复刻；LLM 通过后端统一适配器接入。MVP 只实现和验收阿里云百炼 `qwen-flash` 云 API。兼容 OpenAI API 协议的自部署模型 Base URL 仅作为后续可配置扩展点，不属于本次实现验收范围。自部署不按第三方 API token 计费，但需承担 GPU/云服务器、运维和带宽成本；是否更便宜取决于并发、用量和实例规格。
- 当前火山引擎录音文件识别极速版要求 ASR 能下载音频 URL。后端将录音保留在有 5 分钟 TTL 的进程内存表，并为每条音频生成不可猜测、限次访问的签名下载 URL；ASR 必须在到期前下载，ASR 完成即删除，过期后台清理。服务端不写临时文件、不配置对象存储；服务端重启会清空内存并使链接失效，此时请求失败并可重新提交录音。该方案要求 `PUBLIC_BASE_URL` 是火山服务可访问的公网 HTTPS 地址；本机 localhost 开发无法调用真实 ASR，需部署到公网测试环境或后续接入支持二进制上传的 ASR 适配器。
- 翻译固定 `zh → en`。LLM 请求包含固定翻译指令、当前对话滚动摘要、最近 6 轮和最新 ASR 文本；要求只返回译文以及符合上述 JSON schema 且不超过 1,000 tokens 的更新摘要，不生成聊天回复。每次调用最大总 context 32K，最大完成 tokens 16K；请求上下文分别受摘要/历史限制。识别空结果、token 超额或上游错误时停止后续流程，不合成空文本。
- LLM 连接错误/超时可用原 ASR 文本重试；本次成功前不登记为已完成用量，不丢弃客户端录音。成功后用供应商响应的真实 token usage 计入额度。
- TTS 仅合成译文，选择账号已开通的英文官方音色或用户已克隆音色。具体 speaker ID 通过服务端配置，不在代码中猜测或写入无法验证的 ID。
- 音色复刻使用服务端 API；供应商账号需先开通复刻能力与音色槽位/资源。只允许使用获得合法授权的声音。供应商 API 协议也要求上传者有权处理声音及获得个人信息主体同意。

### 3.4 Android 安装包

- Capacitor 包装 PWA 静态资源，保留 HTTPS 后端 API 地址配置。
- 产出可侧载的 debug APK 供内部测试；签名发布包、商店上架和公开分发配置暂不包含。
- 真机麦克风授权、音频播放、网络权限和 APK 构建需要 Android SDK/JDK。若当前开发环境未安装，提供可复现的构建步骤和明确说明。

## 4. 数据与隐私

- 录音经用户点击结束后，才上传至自有后端并转发至语音服务；应用服务端不持久化录音。为适配火山引擎 ASR 的 URL 输入方式，录音在进程内存中短暂暴露为一次性、5 分钟过期签名 URL；ASR 完成后立即释放，不写入文件或对象存储。
- 对话原文、译文和摘要保存在设备本地 IndexedDB；使用云 LLM 翻译时，当前请求文本、该对话摘要和最近 6 轮会发送给阿里云百炼。设置、对话和当前音色不在设备间同步。
- 克隆音色 ID 属于供应商账号资源，首版由账号持有人负责管理；不能声称供应商不保存样音或克隆模型。
- 共享口令不能放进前端构建产物；以服务端口令交换短期 HttpOnly、SameSite 会话。
- 生产部署必须使用 HTTPS；开发环境允许本机地址。

## 5. 成功标准

1. Android Chrome 可请求麦克风权限、开始和结束录音，并看到明确录音状态。
2. 静音阈值可调；达到阈值显示倒计时，继续说话可取消，倒计时结束后进入处理。
3. 配好服务凭证和资源权限后，用户可以真实获得中文识别原文、英文翻译及可播放的英文音频。
4. 语速在 0.5×–2.0×间以 0.1×递增；改变后影响当前音频播放时长。浏览器支持时设置 `preservesPitch` 保持音高；不支持时允许音高随速率变化，不把音高保持作为通过条件。预置音色可以选择和预览。
5. 有授权确认的样音可发送到克隆接口；未确认时客户端和服务端都拒绝请求。
6. PWA 可安装到主屏幕；Android 项目可构建 APK。
7. 音频原件不会写入服务端持久化存储，云端密钥不会出现在前端资源或 API 响应。
8. 可以创建/切换/删除最多 10 个本地对话；每条译文能利用摘要和最近 6 轮保持专名与指代一致。
9. 服务端逐对话累计并硬性执行 24 小时已处理录音时长和 1,500,000 LLM tokens 两个上限，并展示用量。

## 6. 已知依赖和风险

- 尚未提供火山引擎 API Key、ASR/TTS 资源 ID、预置音色授权、克隆音色资源和阿里云百炼 API Key，因此源码可实现真实接入，但真实云端调用需在本地配置这些内容后才能验证。
- 默认 LLM 是阿里云百炼 `qwen-flash`；需要开通模型服务并确认账号/地域可用。模型价格可能变化，后端适配器可切换同协议云模型或自部署模型；自部署可省第三方模型 API 账单，但不是零成本。
- 24 小时是单个对话的累计“提交处理音频时长”限额，不表示 ASR/TTS 服务免费。10 个对话的语音服务总费用仍受各语音模型与音色授权实际价格影响，需在供应商控制台配置余额告警。
- 火山引擎新旧 API 版本、资源 ID、语音克隆槽位和费用取决于账号控制台；规格中不承诺未确认的免费额度或预置音色列表。
- 音色复刻 V3 API 的提供、训练、查询和删除能力需以账号实际开通接口为准。若账号侧没有删除 API，用户须在供应商控制台删除；应用只负责解除本地引用并阻止继续使用。
- 浏览器 MediaRecorder 对音频编码格式支持不同。客户端上传前需将录音 MIME 类型带给后端；服务端使用 ffprobe 验证容器和时长、必要时使用 ffmpeg 转码，因此部署环境需安装 FFmpeg。
- PWA 麦克风访问需要 HTTPS（localhost 除外）。分享给朋友的可用 URL 需要部署到有 HTTPS 的静态站点和公网 FastAPI 服务；真实 Volcengine ASR 还要求公网 HTTPS `PUBLIC_BASE_URL` 供其拉取带时效签名的内存音频。本地完成时只交付源码、APK 构建配置和部署说明，不擅自部署外部服务。
- 语速播放速率依赖 Android WebView/Chrome 实际实现，需在目标 Android 设备上确认听感；厂商 TTS 语速参数作为替代或后续合成策略。

## 7. 方案选择记录

- **方案 A：** 只做 PWA，交付快但没有独立 APK。
- **方案 B：** 只做 Android 原生 App，录音能力稳但分享与迭代成本更高。
- **方案 C（已确认）：** React PWA + Capacitor Android APK，共享 UI 与业务逻辑，后端服务处理所有云 API。用户明确选择“两个都要”。
